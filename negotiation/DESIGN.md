# 협상 화면 구성

| 경로 | 사용자와 기능 |
|---|---|
| `/app` | 공급사와 주고받은 메시지, 구매팀의 판단 카드와 협상 기준을 한 화면에서 확인한다. |
| `/play` | 사용자가 공급사 역할로 견적을 보내고, 구매 담당자로 역할을 전환해 승인이나 검토를 처리한다. |
| `/` | 판단 이력, 후보 조건과 권한 검사를 확인하고 보존된 합성 협상 기록을 재생한다. |

공급사 화면에는 구매팀의 한도와 대안 견적을 표시하지 않는다. 구매팀은 승인 카드에서 특정 조건과 버전을 확인한다. 코드는 전송 직전에 그 조건의 권한을 다시 검사한다.
